# SrotAI

> The intelligence that structures the internet.

SrotAI is an AI-powered web data system that collects scattered information
from public websites and transforms it into clean, structured and usable data.

## Problem

Useful information is spread across websites, pages, PDFs and APIs.
People must manually search, copy and organize this information.

## Solution

SrotAI allows a user to provide a website and describe the information they
need. The system will traverse the website, extract the relevant information,
clean it and return structured results.

## Planned Workflow

1. The user enters a public website address.
2. The user describes the required information.
3. SrotAI visits permitted pages on the website.
4. AI identifies and extracts relevant information.
5. The ETL pipeline cleans and standardizes the collected data.
6. The results are displayed in a table.
7. The user can download the results as CSV or JSON.
